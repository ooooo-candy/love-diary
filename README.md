# 朝暮 · 恋爱记录 App

一个只属于你们两个人的恋爱记录本：写记录、传照片、看恋爱天数、数着重要日子过日子。
纯前端实现，**零依赖、零构建**，所有数据只保存在你自己的设备里，不会上传。

## 运行

```bash
npm start        # 等价于 node server.js
```

然后打开 http://localhost:5173 （手机上把地址换成电脑的局域网 IP 即可）。

> 也可以直接双击 `index.html` 打开，功能同样可用（此时浏览器不允许使用 IndexedDB，
> 会自动降级为压缩后存 localStorage，照片容量较小，建议用 `npm start` 方式运行）。

### 账号体系（不需要短信，注册即用）

- **注册**：两种方式随便挑
  - **用户名注册**：用户名（3~20 位字母数字下划线）+ 密码 + 密保问题
  - **邮箱注册**：邮箱 + **邮箱验证码** + 密码 + 密保问题（用户名会自动生成）
  - 注册完会给一串**恢复码**（只显示一次，请保存）
- **登录**：一个输入框，填**用户名或邮箱**都能登
- **忘记密码**（三条路，都能保住记录）：
  1. **邮箱验证码** → 收到邮件后直接设新密码（需已绑定邮箱）
  2. 答对**密保问题** → 设新密码
  3. 以上都不行 → 用**恢复码**重设
- **账号安全**：绑定/更换/解绑邮箱（走验证码）、改密码、改密保问题、重新生成恢复码
  - 老账号（用户名注册的）在绑定邮箱后，就可以用邮箱登录、收验证码找回了，两边互通
- **邮件服务**：用 QQ 邮箱 SMTP 发送，配置方法见 `cloud/README.md` 第 4 步；未配置时自动降级为「验证码显示在界面上」的演示模式

安全性说明：密码、密保答案、恢复码全部用 `scrypt` 加盐哈希存储，服务端不保存明文；
密保答案连续答错 5 次会锁定 10 分钟（防暴力猜）。

> 密保答案不区分大小写、会自动忽略空格和标点，例如 `2023-05-20` 和 `2023 0520` 都算对。

## App 更新方式（不用重装）

Android 包已配置为「加载线上页面」模式（`android-app/capacitor.config.json` 里的 `server.url`）：
App 打开时直接加载 CloudBase 上的最新前端页面。

- **以后改前端只需 `npm run publish`**，手机上打开就是新版，**不用重新打包、不用重装**
- 万一界面没变，进「我们 → 检查更新」点一下即可强制刷新
- 数据都在云端，重装 App 只要重新登录，记录和照片都不会丢
- 首次打包给别人的包（把前端打进 APK 的那种）才需要重装，这版之后就不用了

## 功能

- **首页**：恋爱天数大卡片、重要日子倒计时（在一起周年 / 自定义纪念日、生日）、今日提醒、最近记录
- **时光轴**：按月分组的记录流，支持关键词搜索、按心情 / 标签筛选
- **相册**：所有照片按时间倒序九宫格展示，点击进入全屏灯箱（键盘 ←/→/Esc、移动端按钮切换）
- **我们**：恋爱天数 / 记录数 / 照片数 / 连续记录天数、心情分布图、记录日历热区
- **写记录**：多图上传（点击 / 拖拽 / 粘贴，最多 9 张，自动压缩）、心情、地点、标签、日期
- **设置**：双方昵称与头像、5 套主题色、深色模式、重要日子管理
- **备份**：一键导出 JSON（含全部照片），随时导入恢复

## 技术说明

- 存储：照片优先存入浏览器 **IndexedDB**（容量大）；不支持时自动降级为压缩后的 base64 存 localStorage
- 图片上传时在本地用 canvas 压缩（最长边 1600 / 质量 0.85），不产生任何网络请求
- 数据变更后建议定期在「我们 → 导出备份」里存一份文件
