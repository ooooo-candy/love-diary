# 我们的小日子 · 恋爱记录 App

一个只属于你们两个人的恋爱记录本：写记录、传照片、看恋爱天数、数着重要日子过日子。
纯前端实现，**零依赖、零构建**，所有数据只保存在你自己的设备里，不会上传。

## 运行

```bash
npm start        # 等价于 node server.js
```

然后打开 http://localhost:5173 （手机上把地址换成电脑的局域网 IP 即可）。

> 也可以直接双击 `index.html` 打开，功能同样可用（此时浏览器不允许使用 IndexedDB，
> 会自动降级为压缩后存 localStorage，照片容量较小，建议用 `npm start` 方式运行）。

1. 一方：手机号登录 → 创建本子 → 在「我们」页复制邀请码
2. 另一方：手机号登录 → 「用邀请码加入」→ 输入邀请码

## 功能

- **首页**：恋爱天数大卡片、重要日子倒计时（在一起周年 / 自定义纪念日、生日）、今日提醒、最近记录
- **时光轴**：按月分组的记录流，支持关键词搜索、按心情 / 标签筛选
- **相册**：所有照片按时间倒序九宫格展示，点击进入全屏灯箱（键盘 ←/→/Esc、移动端按钮切换）
- **我们**：恋爱天数 / 记录数 / 照片数 / 连续记录天数、心情分布图、记录日历热区
- **写记录**：多图上传（点击 / 拖拽 / 粘贴，最多 9 张，自动压缩）、心情、地点、标签、日期
- **设置**：双方昵称与头像、5 套主题色、深色模式、重要日子管理
- **备份**：一键导出 JSON（含全部照片），随时导入恢复

## 技术说明

- 存储：照片优先存入浏览器 **IndexedDB**（容量大）；不支持时自动降级为压缩后的 base64 存 localStorage
- 图片上传时在本地用 canvas 压缩（最长边 1600 / 质量 0.85），不产生任何网络请求
- 数据变更后建议定期在「我们 → 导出备份」里存一份文件
